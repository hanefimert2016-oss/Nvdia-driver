# NvidiaHackintoshDriver

An open-source NVIDIA GPU driver for **Hackintosh** – installing macOS on
non-Apple hardware.  The driver is structured as a macOS **kernel extension
(kext)** built on IOKit and supports every RTX card (20xx / 30xx / 40xx)
plus the major GTX 10xx cards out of the box.

---

## Supported GPUs

| Generation | Cards |
|------------|-------|
| GTX 10xx (Pascal) | GTX 1050, 1050 Ti, 1060 (3 GB / 6 GB), 1070, 1070 Ti, 1080, 1080 Ti |
| RTX 20xx (Turing) | RTX 2060, 2060 Super, 2070, 2070 Super, 2080, 2080 Super, 2080 Ti |
| RTX 30xx (Ampere) | RTX 3050, 3060, 3060 Ti, 3070, 3070 Ti, 3080, 3080 Ti, 3090, 3090 Ti |
| RTX 40xx (Ada)    | RTX 4060, 4060 Ti, 4070, 4070 Super, 4070 Ti, 4080, 4090 |

---

## Architecture

\`\`\`
NvidiaController          (top-level IOService; matched by IOKit via Info.plist)
  └── NvidiaPCIDevice     (PCI discovery, MMIO + framebuffer BAR mapping)
        └── NvidiaDisplayController  (IOFramebuffer; drives display engine)
\`\`\`

### Driver phases

| Phase | What it does |
|-------|--------------|
| **Phase 1 – single display** | Programs the GPU display engine with a 1920×1080@60 Hz CRTC timing so that macOS sees exactly one monitor immediately after boot. |
| **Phase 2 – acceleration** | Wakes the PGRAPH (2-D / 3-D) engine and the FIFO command processor so that the WindowServer can submit Metal / OpenGL draw calls directly to the GPU. |

### Display modes supported

| Mode ID | Resolution | Refresh |
|---------|-----------|---------|
| 1 | 1920×1080 | 60 Hz |
| 2 | 2560×1440 | 60 Hz |
| 3 | 3840×2160 | 30 Hz |
| 4 | 3840×2160 | 60 Hz |
| 5 | 1280×720  | 60 Hz |

## Building

### Prerequisites (macOS only for full build)

* macOS 12 Monterey or later
* Xcode 14+ with command-line tools (\`xcode-select --install\`)
* A Hackintosh bootloader: [OpenCore](https://github.com/acidanthera/OpenCorePkg)

### Full kext build (macOS)

\`\`\`bash
make all
\`\`\`

The kext bundle is placed in \`NvidiaHackintoshDriver.kext/\`.

### Syntax check + unit tests (any platform)

\`\`\`bash
make lint     # clang syntax-check of all source files
make validate # XML validity check of Info.plist
make test     # compile and run unit tests
\`\`\`

## Installation (Hackintosh)

> ⚠️ **Disable SIP** before loading unsigned kexts.
> Boot with \`csr-active-config=0x03\` in your OpenCore \`config.plist\`.

1. Copy the kext to \`/Library/Extensions/\`:

   \`\`\`bash
   sudo cp -r NvidiaHackintoshDriver.kext /Library/Extensions/
   sudo chown -R root:wheel /Library/Extensions/NvidiaHackintoshDriver.kext
   sudo chmod -R 755 /Library/Extensions/NvidiaHackintoshDriver.kext
   \`\`\`

2. Rebuild the kext cache:

   \`\`\`bash
   sudo kextcache -i /
   \`\`\`

3. Reboot.

4. Verify the kext loaded:

   \`\`\`bash
   kextstat | grep NvidiaHackintosh
   \`\`\`

## CI / GitHub Actions

The workflow (\`.github/workflows/build-and-test.yml\`) runs automatically on
every push / pull request:

| Job | Runner | What it checks |
|-----|--------|---------------|
| \`lint-and-validate\` | Ubuntu | XML validity of Info.plist; clang syntax-check of all \`.cpp\` / \`.h\` |
| \`unit-tests\` | Ubuntu | Compiles and runs 12 unit tests (device-ID lookup, timing arithmetic, …) |
| \`build-macos\` | macOS | Full kext binary build; uploads kext artefact |
| \`debug-build\` | macOS | Rebuild with \`-g -O0 -fsanitize=address -DDEBUG\` for debugging |

## File structure

\`\`\`
.
├── src/
│   ├── NvidiaDeviceIDs.h          # PCI device-ID table for all supported GPUs
│   ├── NvidiaPCIDevice.h/cpp      # IOPCIDevice wrapper (MMIO / FB mapping)
│   ├── NvidiaDisplayController.h/cpp  # IOFramebuffer (display engine + accel)
│   └── NvidiaController.h/cpp    # Top-level IOService
├── stubs/                         # Minimal IOKit headers for Linux CI
├── NvidiaHackintoshDriver.kext/
│   └── Contents/
│       ├── Info.plist             # IOKit personalities (all supported IDs)
│       └── MacOS/                 # kext binary (generated by make)
├── tests/
│   └── test_device_ids.c          # Unit tests (platform-agnostic C)
├── Makefile
└── .github/workflows/build-and-test.yml
\`\`\`
